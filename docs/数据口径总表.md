## 0. 一页速查（最容易踩的 16 条）

| # | 项 | 口径 |
|---|---|---|
| 1 | 比例单位 | **小数**，`0.0974` 表示 9.74%。后端不返回 `"9.74%"` |
| 2 | 金额单位 | 人民币元 |
| 3 | 日期 | `YYYY-MM-DD`，月份 `YYYY-MM`，时区 Asia/Shanghai |
| 4 | 月度区间 | 自然月内**第一个到最后一个交易日**，不是 30 天滚动 |
| 5 | 净值 `nav` | **单位净值，永不复权** |
| 6 | 复权 | 只通过 `total_return_index` 体现，区间收益用它 |
| 7 | 复权基准日 | **数据源首日**（≈基金成立），所以月内首值不是 1 |
| 8 | 持仓权重 | 占基金净值比例，`∈ [0, 1]`，来自季报百分比 ÷ 100 |
| 9 | 权重和 | 前十大之和 < 1 是正常的，差额即残差 |
| 10 | 残差 | 必须显式返回，**不许摊进已知持仓** |
| 11 | 对账容差 | `0.001`（0.1%） |
| 12 | 行业分类 | 申万一级（2021 版） |
| 13 | 缺失值 | `null` + 说明，**禁止用 0 或前值填充** |
| 14 | 数值精度 | 内部不截断；存储 `round(x, 8)`，净值展示 4 位 |
| 15 | 抓取失败 | 不等于没数据：降级到本地并标注 `as_of` |
| 16 | 计算位置 | 只在 `engine/`；抓取在 `data_pipeline/`；插件不碰网络 |

### 1.2 NavPoint —— 净值点（`ctx.data["nav_series"]`）

| 字段 | 类型 | 单位 | 必填 | 约束 | 示例 |
|---|---|---|---|---|---|
| `date` | str | — | 是 | ISO 日期，升序唯一 | `"2026-10-08"` |
| `nav` | float | 元/份 | 是 | `> 0`，单位净值 | `2.761` |

### 1.3 总回报点（`ctx.data["nav_total_return"]`）

| 字段 | 类型 | 必填 | 约束 | 示例 |
|---|---|---|---|---|

| `period_return` | float \| null | 区间收益 | 否 | 小数 | `0.0235` |

| 字段 | 类型 | 必填 | 约束 | 示例 |

### 1.8 ContributionItem / AttributionResult —— 归因

**ContributionItem**

| 字段 | 类型 | 约束 |
|---|---|---|
| `code` / `name` | str | 非空 |
| `industry` | str | 申万一级，空串=未映射 |
| `weight` | float | `[0,1]`，**漂移后权重** |
| `period_return` | float | 该股区间收益 |
| `contribution` | float | `= weight × period_return` |

**AttributionResult**

| 字段 | 类型 | 约束 |
|---|---|---|
| `month` | str | `YYYY-MM` |
| `items[]` | tuple | ContributionItem 列表 |
| `industries[]` | tuple | `{industry, weight, contribution, codes[]}` |
| `total_contribution` | float | `= Σ items.contribution` |
| `residual_return` | float | 未披露部分，**即使为 0 也必须返回** |
| `notes[]` | tuple | 口径说明（必须含漂移假设） |

### 1.9 Anomaly / AnomalyRule —— 异动

**Anomaly**

| 字段 | 类型 | 约束 |
|---|---|---|
| `code` / `name` | str | 非空 |
| `date` | str | ISO 日期 |
| `kind` | enum | `price` / `volume` / `relative` / `industry` |
| `value` | float | 价格与相对用小数，量能为倍数，行业为名次 |
| `note` | str | **只描述事实，不解释原因** |

**AnomalyRule（默认阈值）**

| 字段 | 默认 | 含义 |
|---|---|---|
| `price_move_pct` | `0.05` | 单日涨跌绝对值 ≥ 5% |
| `volume_ratio` | `2.0` | 成交额 ≥ 20 日均值 2 倍 |
| `relative_pct` | `0.04` | 个股 − 行业 ≥ 4% |
| `industry_top_n` | `3` | 行业涨跌排名前/后 3 |

## 3. 计算口径（公式级）

| 指标 | 公式 | 精度 | 边界 |
|---|---|---|---|
| 区间收益 | `end_nav / start_nav − 1` | round 8 | 有效点 < 2 抛 `ValueError` |
| 最大回撤 | `min(nav_t / peak_t − 1)`，peak 为历史新高 | round 8 | 单调上涨时为 `0.0` |
| 权重漂移 | `w_end,i = w_start,i × (1+r_i) / (1+R)` | round 8 | `1+R ≤ 0` 抛错 |
| 单股贡献 | `contribution = weight × period_return` | round 8 | weight 用**漂移后**权重 |
| 行业贡献 | `Σ contribution`（按 industry 分组） | round 8 | 未映射归入空串组 |
| 组合贡献 | `Σ items.contribution` | round 8 | — |
| 残差 | `residual = R − Σ contribution` | round 8 | 必须显式返回 |
| 对账 | `|Σ contribution + residual − R| ≤ 0.001` | — | 超差即视为算法错误 |
| 总回报指数 | `I_t = I_{t−1} × (nav_t + d_t) / nav_{t−1}`，`I_0 = 1` | 不截断 | 首日分红被忽略（锚定日无前值） |

**约定**：以上全部为纯函数，输入相同输出相同，不读全局状态、不访问网络。

## 4. 数据源与优先级

```
当日缓存 → 抓取主源 → 抓取备源 → 本地已导入 → 报错
```

| 数据 | 主源 | 备源 | 兜底 | 缓存 | 失败行为 |
|---|---|---|---|---|---|
| 基金净值 | akshare/eastmoney | 蛋卷 `danjuan` | `fund_nav_point` 表 | 6 小时 | 降级并标 `fallback`+`as_of` |
| 基金持仓 | akshare/eastmoney | — | `holding_position` 表 | 7 天 | 降级或返回空 |
| 分红记录 | 东财分红页 `fundf10` | — | 本地 `dividend_per_share` | 7 天 | 降级为不复权 + warning |
| 基金信息 | akshare/eastmoney | — | 本地占位名 | 7 天 | 占位不阻塞 |
| 个股日线 | 新浪 `stock_zh_a_daily` | 腾讯 `stock_zh_a_hist_tx` | — | — | 待接入 |
| 行业指数 | 申万 `index_hist_sw` | — | — | — | 待接入 |

**抓取失败 ≠ 没数据**。回退到本地时必须给 `as_of`，页面上标明"本地数据，截至 X 月 X 日"。

## 5. 校验阈值（`engine/validation.py`）

| 规则 | 阈值 | 失败处理 | 函数 |
|---|---|---|---|
| 净值合法性 | `nav > 0` 且可转 float | 剔除并记 warning | `clean_nav_series` |
| 日期唯一 | 无重复 | 保留首个 + warning | `clean_nav_series` |
| 日期升序 | 排序后返回 | 自动 | `clean_nav_series` |
| 最少点数 | `≥ 2` | error → 接口 404 | `clean_nav_series` |
| 代码格式 | 6 位数字 | error | `validate_holdings` |
| 权重范围 | `0 ≤ w ≤ 1` | error | `validate_holdings` |
| 权重和 | `≤ 1 + 1e-6` | error | `validate_holdings` |
| 残差空间 | 权重和 `< 0.999` | warning | `validate_holdings` |
| 对账 | 差 `≤ 0.001` | error | `validate_attribution` |

## 6. 枚举值

| 字段 | 取值 | 含义 |
|---|---|---|
| `PluginResult.status` | `ready` | 算法已实现并有结果 |
| | `stub` | 占位，算法未接入 |
| 接口结果 `status` | `ready` / `stub` / `error` | 多一个执行失败态 |
| `Anomaly.kind` | `price` / `volume` / `relative` / `industry` | 四类异动 |
| `meta.source` | `akshare.eastmoney` / `danjuan` / `local_import` / `cache` | 数据来源 |
| `meta.dividend_source` | `eastmoney` / `local_import` / `unavailable` | 分红来源 |
| `meta.fallback` | `true` | 表示走了本地兜底 |
| `ValidationReport` | `errors` / `warnings` | 不可用 / 已自动处理 |
