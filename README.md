# fund-review

投后月度回顾工具。面向个人投资者，输入持仓与净值数据，输出月度投资回顾报告与基金涨跌归因。

## 核心功能

- 导入持仓快照与基金净值数据
- 计算区间收益（含分红复权）
- 对基金涨跌做归因拆解（行业、风格、个股选择）
- 生成可导出的月度回顾报告
