# fund-review

投后月度回顾工具。面向个人投资者，输入持仓与净值数据，输出月度投资回顾报告与基金涨跌归因。

## 核心功能

- 导入持仓快照与基金净值数据
- 计算区间收益（含分红复权）
- 对基金涨跌做归因拆解（行业、风格、个股选择）
- 生成可导出的月度回顾报告

## 新人第一步

克隆仓库后，先装防误推的钩子：

```bash
bash scripts/install-hooks.sh
```

装完直接推 `main` 会被本地拦截。

注意：这只是本地约束。GitHub 的分支保护功能在**免费账号的私有仓库**上用不了（需要 Pro），所以这道防线得靠每个人自觉装一次。装了之后至少不会手滑。
