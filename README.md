# fund-review

投后月度回顾工具。面向个人投资者，输入持仓与净值数据，输出月度投资回顾报告与基金涨跌归因。

## 核心功能

- 导入持仓快照与基金净值数据
- 计算区间收益（含分红复权）
- 对基金涨跌做归因拆解（行业、风格、个股选择）
- 生成可导出的月度回顾报告

## 新人第一步

克隆仓库后，先装防误推的钩子：

```bash
bash scripts/install-hooks.sh
```

装完直接推 `main` 会被本地拦截。

服务端也已启用分支保护（`protect-main` 规则集）：禁止删除 `main`、禁止强推、必须走 PR 且至少 1 人 approve。本地钩子只是提前一步拦住手滑，真正决定改动能否进主干的是 GitHub 那边。

组长（仓库管理员）留了紧急绕过通道，仅用于主干坏掉必须立刻修的情况，事后要在群里说明。

## 协作方式

先读 [`docs/小组协作手册.md`](docs/小组协作手册.md)。里面写了分支规范、任务卡模板、PR 规矩、以及怎么给框架加一个新功能。

2. 不改别人的模块目录不打招呼
3. 归因算法不过对账测试，不算完成
